# 社交与爱奇艺字体及文字规则

本文档以当前仓库中的规则文件和渲染代码为准，覆盖 `social`（社交）与 `iqiyi`（爱奇艺）两条业务线。文档中的坐标均为 9:16 参考画布 `496 x 864` 的像素坐标；源视频应为 9:16，FFmpeg/libass 按比例缩放到实际视频尺寸。

## 1. 统一输入与时间规则

| 项目 | 规则 |
| --- | --- |
| 字幕字段 | `captions` 必须是非空数组；每项包含 `start`、`end`、`text`。 |
| 时间合法性 | `start >= 0`、`end > start`、片段按时间升序且不可重叠；`text` 不能为空白。 |
| 字幕时间 | 字幕只在各自输入片段的 `start ~ end` 显示，不自动延长。 |
| 文本转义 | 输入中的 `\\`、`{`、`}` 会按 ASS 文本规则转义，避免被解析为控制标签。 |
| 标题/正文关系 | 社交标准版不接受顶层 `title`；奔现使用独立的 `social_title`、`social_title_style`。爱奇艺使用 `title` 和 `title_mode`。 |
| 位置基准 | `x=248` 是画布水平中心；显式 `\\pos` 的坐标以规则文件为准。 |

## 2. 社交业务线

### 2.1 标准社交字幕（含数字人、空镜）

#### 字体与视觉参数

| 字段 | 规则 |
| --- | --- |
| 配置入口 | `rules/social.json` 的 `subtitle` |
| 字体 | `Microsoft YaHei`（微软雅黑）；渲染字体名同为 `Microsoft YaHei`，以粗体样式输出 |
| 字号 | `36px` |
| 字体颜色 | 普通文字 `#FFFFFF`（白色） |
| 黑边 | `1.5px`，颜色 `#101010` |
| 阴影 | `1px` |
| 横纵缩放 | `ScaleX=100%`、`ScaleY=100%` |
| 对齐与位置 | 底部居中；显式位置 `x=248, y=629` |
| 分行 | 开启标点优先分行、中文语义分行；每个切分片段最多 10 个字。 |

#### 关键词高亮

以下完整短语在标准社交字幕中使用黄字黑边，其他文字保持白字黑边：

`同城夜聊`、`同城约会吧`、`爱聊`、`爱聊唯西`、`爱聊新远方`、`会会`、`会会新远方`、`会会宇视`、`本地寻友`、`他趣`、`闪糖`、`甜话`。

- 高亮填充色：`#FFE500`。
- 高亮黑边色：`#101010`。
- 按短语长度从长到短匹配，例如命中 `爱聊唯西` 时不会先把其中的 `爱聊` 单独着色。
- 高亮只在 `social` 标准版生效，不会泄漏到爱奇艺或其他模板。
- 高亮不改变字号、位置、行数和时间。

#### 社交 CTA：`点击下方立即使用`

| 项目 | 规则 |
| --- | --- |
| 输入字段 | `selected_products`，必须是字符串数组；数组项不可为空。 |
| 显示条件 | 数组与以下任一商品有交集时显示：`爱聊唯西`、`爱聊新远方`、`会会新远方`、`甜话`。 |
| 不显示条件 | 字段省略、传空数组，或仅选择其他商品时不显示 CTA。 |
| 适用视频 | 配置声明适用于 `digital_human`、`empty_shot`；当前渲染器对两类不再分支，规则完全一致。 |
| 文案字体 | `Microsoft YaHei` |
| 文案字号 | `28px` |
| 文案颜色 | `#101010`（深色字） |
| 文案描边 | `2.5px` 白边，阴影 `1px` |
| 箭头 | 使用 `assets/images/social-cta-arrow.png`，红色语义；渲染尺寸 `24 x 40px`。 |
| 组布局 | 文案逐字单独定位，行距 `24px`；文字与箭头间隔 `6px`；整体 `group_offset_y=-20px`。 |
| 位置 | 规则原点 `position=(-900,0)` 经 1080x1920 到 496x864 换算为 `x≈41.33, y=432`；视觉上位于画布左侧中部。 |
| 时间 | CTA 事件为 `0:00:00.00 ~ 9:59:59.00`，即整段输出视频持续显示。 |

### 2.2 社交“奔现”正文

#### 选填逻辑

- 通过 `social_variant: "奔现"` 进入。
- `social_font` 可选六项；省略时默认 `标题圆`。
- `social_title` 与 `social_title_style` 是独立标题字段，均可选；只填一个会校验失败：标题样式必须依赖标题，标题必须同时指定样式。
- 奔现不使用顶层 `title`；顶层 `title` 会被拒绝。
- 字号和位置是固定规则，调用方不得通过 `social_title_font_size` 或 `social_title_position` 覆盖；若传入，必须分别等于 `35px` 和 `{x:248,y:50}`。

#### 正文字体、比例与位置

所有奔现正文字号均为 `32px`，白字、`1.5px` 黑边、`1px` 阴影，左对齐，位置固定为 `x=50, y=700`。`requested_position=(-260,-800)` 是旧逻辑坐标，当前实际使用画布坐标。

| 选项（`social_font`） | 渲染字体/字体文件 | ScaleX | ScaleY | 基线偏移 |
| --- | --- | ---: | ---: | ---: |
| `标题圆` | `YouSheBiaoTiYuan` / `assets/fonts/YousheTitleYuan.ttf` | 108% | 117% | 0px |
| `抖音体` | `DouyinSans` / `assets/fonts/DouyinSansBold.ttf` | 92% | 88% | 0px |
| `新青年体` | `WenYue XinQingNianTi (Non-Commercial Use) W8` / `assets/fonts/WenYueXinQingNianTi.otf` | 110% | 91% | 0px |
| `美玲体` | `HelloFont MeiLingTi` / `assets/fonts/MeiLingTi.ttf` | 100% | 100% | 0px |
| `江户招牌` | `HelloFont ID JiangHuZhaoPaiHei` / `assets/fonts/JiangHuZhaoPai.ttf` | 100% | 100% | 0px |
| `仓耳丰黑` | `TsangerFengHei` / `assets/fonts/CangErFengHei.ttf` | 100% | 100% | 0px |

#### 正文分行与显示

- 逗号、句号、感叹号、问号及其他 Unicode 标点作为分隔符。
- 输出中删除分隔标点；原文中的普通空格保留。
- 一个输入字幕片段生成一个同步字幕事件，分隔后的多行用 ASS `\\N` 同时显示，不会逐句弹出。
- 正文事件只覆盖输入 captions 的时间窗口；不自动加入片头或片尾。

### 2.3 社交“奔现”标题

#### 固定规则

| 项目 | 规则 |
| --- | --- |
| 字体 | `HYZongYiJ`（仓耳综艺体） |
| 字号 | 固定 `35px` |
| 对齐与位置 | 顶部居中，`x=248, y=50` |
| 时间 | 从所有正文 captions 的最早开始时间到最晚结束时间；无正文时不生成标题事件。 |
| 换行 | 按第一个空白字符分为最多两行；无空白时一行；标题标点不自动删除。 |
| 尺寸覆盖 | 不允许自动缩小；标题字号和位置固定。 |

当前可选 `social_title_style` 仅有以下两项，动画及装饰由对应样式规则固定：

| 样式 | 字色 | 描边 | 字形 | 缩放 | 基线偏移 |
| --- | --- | --- | --- | ---: | ---: |
| `心动时刻` | `#FFFFFF` | `#F35B9B`，`2.5px` | 粗体 | 100% / 100% | 0px |
| `黄色星星` | `#FFFDF4` | `#B85C2E`，`2.5px` | 粗体、斜体 | 100% / 100% | 0px |

## 3. 爱奇艺业务线

### 3.1 爱奇艺数字人字幕

| 字段 | 规则 |
| --- | --- |
| 配置入口 | `rules/iqiyi.json` 的 `subtitle` |
| 字体 | `思源黑体`；实际渲染字体 `SourceHanSansCN-Heavy` |
| 字号 | `35px` |
| 字体颜色 | `#FFFFFF` |
| 黑边 | `1.5px`，颜色 `#101010` |
| 阴影 | `1px` |
| 横纵缩放 | `ScaleX=100%`、`ScaleY=100%` |
| 对齐与位置 | 底部居中；`x=248, y=629` |
| 分行 | 标点优先、中文语义分行；每个切分片段最多 10 个字 |
| 关键词高亮 | 无。爱奇艺不会使用社交业务线的黄色关键词列表。 |
| 时间 | 严格使用每个 `captions` 片段的 `start ~ end`。 |

爱奇艺字幕只由 `captions` 驱动，脚本中的 `title` 不会改变字幕字号、位置或分行逻辑。长字幕按标点和语义边界拆成多个定时事件。

### 3.2 爱奇艺顶部标题

#### 选填逻辑

- `title` 由调用方提供；为空时不生成标题事件。
- `title_mode` 只能是 `"one"` 或 `"two"`，默认 `"two"`。
- 标题按第一个空白字符切分；没有空白时整段按第一行样式显示。
- 标题事件固定覆盖 `0:00:00.00 ~ 9:59:59.00`，与字幕 captions 时间无关。

#### 字体与摆放

| 项目 | 第一行/前半段 | 第二行/后半段 |
| --- | --- | --- |
| 字体 | `HYZongYiJ` | `HYZongYiJ` |
| 字号 | 30px | 30px |
| 填充色 | `#FFE500`（黄） | `#FFFFFF`（白） |
| 描边色 | `#101010`（黑） | `#ED1C2E`（红） |
| 描边宽度 | 3px | 3px |

- 共同位置基准：水平居中 `x=248`，第一行 `y=82.5`。
- `title_mode="two"`：第一段显示在 `y=82.5`；第二段显示在 `y=120`，行间净间距 `7.5px`（`30 + 7.5 = 37.5`）。
- `title_mode="one"`：只生成一条居中事件；第一个空白前的文字为黄字黑边，空白后的文字为白字红边，并保留一个空格。
- `title_mode="two"` 下若标题只有一段，只显示黄字黑边第一行，不补第二行。

## 4. “免费”标语核查结论

当前仓库未发现“免费”“免费标语”或同义文案对应的配置字段、字体样式、选填条件、坐标或渲染分支：

- `rules/social.json`、`rules/iqiyi.json` 均没有免费文案字段。
- `scripts/generate_video.py`、`scripts/render_template.py` 没有免费文案判断或事件生成逻辑。
- 示例脚本也没有免费标语字段。

因此当前版本不能据现有规则自动渲染“免费”标语。若产品要求加入，应补充至少以下定义后再实现：文案固定值或可编辑字段、字体/字号/颜色/描边、显示条件、画布坐标、显示时长，以及与爱奇艺标题或字幕的遮挡优先级。

## 5. 业务线隔离与禁止项速查

| 场景 | 允许内容 | 禁止/不会发生 |
| --- | --- | --- |
| 社交标准 | 标准字幕、社交关键词高亮、条件 CTA | 顶层标题；奔现标题样式；爱奇艺标题样式 |
| 社交奔现 | 六选一正文 `social_font`；可选标题及两种标题样式 | 覆盖固定字号/位置；只填标题或只填样式；片头片尾自动补字 |
| 爱奇艺 | `captions` 数字人字幕；可选 `title` + `title_mode` | 社交关键词黄字；社交 CTA；免费标语（当前未实现） |
