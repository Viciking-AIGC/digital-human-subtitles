# 社交规则

本文件只记录社交模板规则，和信息流广告、爱奇艺及其他贴纸模板分开维护。

## 标准社交字幕

- 适用范围：数字人视频和空镜视频，沿用标准片中字幕时间范围。
- 字体：微软雅黑 Bold，36px，白字，1.5px 黑边，1px 阴影，居中显示（画布坐标 `x=248, y=629`）。
- 仅以下完整短语使用黄字黑边，字号、位置和其他样式保持不变：
  `同城夜聊`、`同城约会吧`、`爱聊`、`爱聊唯西`、`爱聊新远方`、`会会`、`会会新远方`、`会会宇视`、`本地寻友`、`他趣`、`闪糖`、`甜话`。
- 黄字颜色为 `#FFE500`，黑边颜色为 `#101010`。关键词按最长短语优先匹配，颜色不会泄漏到其他文字或其他模板。
- 选中 `爱聊唯西`、`爱聊新远方` 或 `会会新远方` 时，额外显示固定 CTA；未选中时不显示。

## “奔现”版式

- 入口：剪辑入口的社交“奔现”选项；正文和标题相互独立，均可从素材库选择，也可直接输入。
- 范围：仅片中显示。片头、片尾不加入标题或正文。
- 标题：可选 `心动时刻` 或 `黄色星星`，使用 `HYZongYiJ`（仓耳综艺体）动画样式；字号固定 `35px`，水平居中，顶部位置固定为画布 `x=248, y=50`。标题按空格分行，最多两行；无空格时显示一行。标题样式的动画、爱心/星星装饰和校准比例由对应模板规则固定，调用方不能覆盖字号或位置。
- 正文：可选以下六种字体：
  `标题圆`、`抖音体`、`新青年体`、`美玲体`、`江户招牌`、`仓耳丰黑`。
- 正文字号固定 `32px`，白字黑边（黑边 `1.5px`、阴影 `1px`），整段同时显示，所有行左对齐。画布位置固定为 `x=50, y=700`；这是对原始逻辑坐标 `x=-260, y=-800` 的画布换算结果。
- 正文按逗号、句号、感叹号、问号等标点分行；标点从输出中删除，行内空格保留。各行属于同一个字幕事件，不逐句弹出。
- 标题和正文都使用相同的片中时间窗口；不自动延伸到片头或片尾。

### 正文字体校准

每种字体的字号仍为 `32px`，仅使用固定的字面比例校准视觉宽高；`baseline_offset_y` 是基线微调值，默认均为 `0`。

### 命令行入口

完整入口为 `scripts/social/社交奔现.py`，固定版式入口为 `scripts/generate_social_benxian.py`。示例：

```bash
python3 scripts/social/社交奔现.py \
  /path/to/input.mp4 /path/to/output.mp4 \
  --title "温柔相遇 在这里遇见专属偏爱" \
  --title-style 心动时刻 \
  --font 新青年体 \
  --text "在这上面认识的女友，在一起已经两个月了，她温柔 体贴 真诚，终于遇见那个满眼都是我的女孩了"
```

JSON 入口使用 `social_variant: "奔现"`、`social_title`、`social_title_style`、`social_font` 和 `captions` 字段；不要添加字号或位置覆盖字段。
